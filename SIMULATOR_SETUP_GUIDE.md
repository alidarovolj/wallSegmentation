# 🎮 Руководство по настройке симулятора маски сегментации

## 🎯 Что это такое?

Система симулятора позволяет тестировать маски сегментации в Unity Editor без реального AR-устройства. Вместо камеры используются тестовые изображения, на которых можно проверить качество сегментации, покраску стен и обнаружение углов.

## ⚡ Быстрая настройка (1 минута)

### Шаг 1: Добавить SimulatorSetup
1. Создайте пустой GameObject в сцене
2. Назовите его `SimulatorSetup`
3. Добавьте компонент `SimulatorSetup`
4. В Inspector проверьте что `Auto Setup On Start = true`

### Шаг 2: Запустить сцену
1. Нажмите Play в Unity Editor
2. Система автоматически настроится
3. Появится UI с тестовыми изображениями
4. Маска будет отображаться поверх изображений

## 🔧 Ручная настройка (если автонастройка не сработала)

### Создание компонентов

1. **SimulatorMaskTester**:
   ```
   GameObject → Create Empty → назвать "SimulatorMaskTester"
   Add Component → SimulatorMaskTester
   ```

2. **AsyncSegmentationManager**:
   - Найдите существующий в сцене
   - В Inspector установите `Enable Simulator Mode = true`
   - Назначьте `Simulator Tester` в соответствующее поле

3. **ARWallPresenter**:
   - Должен уже присутствовать в сцене
   - Никаких дополнительных настроек не требуется

## 🎨 Что вы увидите

### UI Elements
- **Background Image** - тестовое изображение комнаты
- **Mask Overlay** - маска сегментации поверх изображения
- **Control Buttons**:
  - `Next Image` - следующее тестовое изображение
  - `Prev Image` - предыдущее тестовое изображение  
  - `Toggle Mask` - показать/скрыть маску
- **Status Text** - информация о текущем состоянии

### Тестовые изображения
1. **Simple Room** - простая комната с полом, стенами, потолком
2. **Room with Furniture** - комната с мебелью
3. **Solid Color** - сплошной цвет для калибровки

## ⌨️ Управление

### Горячие клавиши
- **SPACE** - Переключить видимость маски
- **N** - Следующее изображение
- **P** - Предыдущее изображение
- **Mouse Click** - Покрасить стены в синий цвет (если включен SimpleClickPainter)

### Кнопки UI
- Все основные функции дублируются кнопками в интерфейсе
- Кнопки создаются автоматически при запуске

## 🔍 Функции тестирования

### Тестирование сегментации
```csharp
// Проверить качество маски
SimulatorMaskTester tester = FindObjectOfType<SimulatorMaskTester>();
tester.SaveCurrentMask(); // Сохранить маску как PNG
```

### Тестирование покраски
```csharp
// Покрасить стены
SimpleClickPainter painter = FindObjectOfType<SimpleClickPainter>();
// Просто кликните мышью в области стены
```

### Тестирование углов и контуров
```csharp
// Получить обнаруженные углы
EdgeCornerDetector detector = FindObjectOfType<EdgeCornerDetector>();
List<Vector2> corners = detector.GetCornersInScreenSpace();
List<Vector2> edges = detector.GetEdgesInScreenSpace();
```

## 🛠️ Диагностика проблем

### Маска не отображается

1. **Проверить консоль**:
   ```
   🎮 Автоматически включен режим симулятора в Unity Editor
   ✅ SimulatorMaskTester полностью инициализирован
   ```

2. **Проверить статус через контекстное меню**:
   ```
   SimulatorSetup → Right Click → Check Status
   ```

3. **Принудительно включить симулятор**:
   ```
   SimulatorSetup → Right Click → Force Enable Simulator
   ```

### Нет тестовых изображений

1. **Перезагрузить изображения**:
   ```
   SimulatorMaskTester → Right Click → Reload Test Images
   ```

2. **Создать UI принудительно**:
   ```
   SimulatorMaskTester → Right Click → Force Create UI
   ```

### TopFormer модель не загружается

1. Убедитесь что `topformer_b_512x512_simplified.onnx` находится в `Assets/Models/`
2. Проверьте что модель назначена в `AsyncSegmentationManager → Model Asset`
3. Посмотрите логи на ошибки загрузки модели

2. **Тестирование на устройстве**:
   - Соберите билд для iOS/Android
   - Проверьте работу на реальном устройстве

3. **Настройка качества**:
   - Отрегулируйте параметры сегментации
   - Оптимизируйте производительность
   - Настройте цвета и прозрачность

## 💡 Советы

1. **Производительность**: В симуляторе отключите ненужные AR компоненты
2. **Отладка**: Используйте `SaveCurrentMask()` для анализа качества
3. **Кастомизация**: Добавьте свои тестовые изображения в `testImages[]`
4. **Автоматизация**: Создайте unit-тесты на базе симулятора
