# Руководство по интеграции AR Mask Interaction

## 🎯 Что создано

Создана система интерактивной 3D-сегментации, которая:
- Преобразует 2D касания экрана в 3D позиции на реальных поверхностях
- Определяет класс объекта (стена/пол/потолок) в точке касания
- Создает 3D маркеры для визуализации результатов
- Интегрируется с существующими системами проекта

## 📁 Созданные файлы

1. **`Assets/Scripts/ARMaskInteraction.cs`** - основной скрипт взаимодействия
2. **`Assets/Scripts/Enhanced Features/ARMaskInteractionIntegrator.cs`** - автоматический интегратор

## 🔧 Быстрая интеграция

### Вариант 1: Автоматическая интеграция (Рекомендуется)

1. Найдите в сцене главный объект (например, Main Camera или AR Session Origin)
2. Добавьте компонент `ARMaskInteractionIntegrator`
3. В Inspector настройте:
   - ✅ `Auto Setup On Start` - включить автоматическую настройку
   - ✅ `Replace Existing Click Handlers` - если хотите заменить SimpleClickPainter
4. Запустите сцену - интеграция произойдет автоматически

### Вариант 2: Ручная настройка

1. Добавьте `ARMaskInteraction` на любой GameObject в сцене
2. В Inspector подключите:
   - `Segmentation Manager` → AsyncSegmentationManager из сцены
   - `Occlusion Manager` → AROcclusionManager (если есть)
   - `Camera Manager` → ARCameraManager из сцены
   - `Ar Camera` → основная AR камера
3. Настройте параметры по желанию

## 🎮 Как использовать

### Основные действия:
- **Касание экрана** → создает 3D маркер в точке касания
- **Долгое касание** → показывает подробную информацию
- **Касание UI** → игнорируется автоматически

### Цвета маркеров:
- 🔴 **Красный** - Стены
- 🟢 **Зеленый** - Пол  
- 🔵 **Синий** - Потолок
- 🟡 **Желтый** - Окна
- 🟣 **Фиолетовый** - Двери
- 🔵 **Голубой** - Другие объекты

## 🎛️ Настройки в Inspector

### ARMaskInteraction:
- `Enable Interaction` - включить/выключить взаимодействие
- `Click Cooldown` - задержка между кликами (сек)
- `Marker Prefab` - префаб для 3D маркеров
- `Class Colors` - цвета для разных классов объектов
- `Enable Debug Logs` - отладочные сообщения

### ARMaskInteractionIntegrator:
- `Auto Setup On Start` - автонастройка при запуске
- `Replace Existing Click Handlers` - замена старых обработчиков
- `Marker Size` - размер маркеров (метры)
- `Marker Material` - материал для маркеров

### Типичные проблемы:

1. **Маркеры не создаются**
   - Проверьте подключение AsyncSegmentationManager
   - Убедитесь что сегментация работает
   - Проверьте логи в Console

2. **Неточное позиционирование**
   - Проверьте настройки AROcclusionManager
   - Убедитесь что AR Session инициализирован
   - Попробуйте на реальном устройстве (не в симуляторе)

3. **Конфликт с другими скриптами**
   - Отключите SimpleClickPainter
   - Проверьте конфликты в SegmentationManager.HandleTap()

## 🎯 Управление через код

```csharp
// Получить компонент
var arMaskInteraction = FindObjectOfType<ARMaskInteraction>();

// Включить/выключить взаимодействие
arMaskInteraction.SetInteractionEnabled(true);

// Очистить все маркеры
arMaskInteraction.ClearAllMarkers();

// Установить новый префаб маркера
arMaskInteraction.SetMarkerPrefab(myCustomMarkerPrefab);
```
