# 🎨 Руководство по настройке покраски стен

## ✅ ИСПРАВЛЕНИЯ В ARWallPresenter

**Проблема:** ARWallPresenter не переключался в режим одного класса при установке цвета.

**Решение:** Добавлены новые методы:
- `SetSingleClassMode(classId, color)` - принудительно устанавливает режим одного класса
- `SetAllClassesMode()` - возвращает в режим всех классов
- Исправлен `SetClassColor()` - теперь автоматически переключает в режим одного класса

## 🛠️ ЧТО НУЖНО СДЕЛАТЬ В UNITY

### 1. Отключите ненужные компоненты
```
❌ ОТКЛЮЧИТЕ: LightweightWallPainter (если есть в сцене)
❌ ОТКЛЮЧИТЕ: IndividualWallPainter (слишком тяжелый)
✅ ОСТАВЬТЕ: SimpleClickPainter
```

### 2. Настройте AsyncSegmentationManager
В Inspector для `AsyncSegmentationManager`:

**Class Visualization секция:**
- ✅ `Show Walls` = **ВКЛЮЧЕНО (true)**
- ❌ `Show All Classes` = **ВЫКЛЮЧЕНО (false)**
- ❌ `Show Floors` = **ВЫКЛЮЧЕНО (false)**
- ❌ `Show Ceilings` = **ВЫКЛЮЧЕНО (false)**
- 🎨 `Paint Color` = **любой цвет (будет переопределен SimpleClickPainter)**

### 3. Настройте ARWallPresenter
В Inspector для `ARWallPresenter`:

**Режимы визуализации:**
- ❌ `Show All Classes` = **ВЫКЛЮЧЕНО (false)**
- 🎯 `Single Class Id` = **0** (класс стен)
- 🎨 `Single Class Color` = **синий** (или любой другой)

### 4. Настройте SimpleClickPainter
В Inspector для `SimpleClickPainter`:

**Настройки:**
- 🎨 `Paint Color` = **Color.blue** (или желаемый цвет)
- ✅ `Enable Painting` = **ВКЛЮЧЕНО (true)**
- ⏱️ `Click Cooldown` = **0.5** (задержка между кликами)

**Автопоиск компонентов:**
- 🔍 `Segmentation Manager` = **автоматически найден**
- 🔍 `Ar Wall Presenter` = **автоматически найден**

## 🚀 КАК ПРОВЕРИТЬ ЧТО ВСЕ РАБОТАЕТ

### 1. Запустите приложение
При старте в логах должно появиться:
```
🧱 Включен режим показа только стен для покраски
🎯 ARWallPresenter принудительно настроен для режима одного класса (стены)
🎨 Простая покраска по клику активирована! Цвет: RGBA(0.000, 0.000, 1.000, 1.000)
```

### 2. Кликните в любом месте экрана
В логах должно появиться:
```
🎨 Стены покрашены в RGBA(0.000, 0.000, 1.000, 1.000) через SetSingleClassMode
🎯 ARWallPresenter: Включен режим одного класса - ID: 0, цвет: 0000FF
```

### 3. Проверьте визуально
- 🧱 Все стены должны стать **синими**
- 🚫 Другие объекты (пол, потолок) **не видны**
- 🎯 Смена цвета происходит **мгновенно**

## 🔧 КОНТЕКСТНЫЕ МЕНЮ ДЛЯ ТЕСТИРОВАНИЯ

Кликните ПКМ на `SimpleClickPainter` в Inspector:
- **"Сбросить цвет стен"** - вернуть серый цвет
- **"Тест: Красный"** - покрасить в красный
- **"Тест: Синий"** - покрасить в синий  
- **"Тест: Зеленый"** - покрасить в зеленый
- **"Тест: Желтый"** - покрасить в желтый

## ❗ ЕСЛИ НЕ РАБОТАЕТ

### Проблема: Стены не меняют цвет
**Решение:**
1. Убедитесь что `Show All Classes = false` в AsyncSegmentationManager
2. Убедитесь что `Show Walls = true` в AsyncSegmentationManager
3. Проверьте что SimpleClickPainter находит компоненты (логи при старте)

### Проблема: Вижу все классы разными цветами
**Решение:**
1. В ARWallPresenter установите `Show All Classes = false`
2. Перезапустите приложение

### Проблема: Клики не работают
**Решение:**
1. Проверьте что `Enable Painting = true` в SimpleClickPainter
2. Убедитесь что кликаете не по UI элементам
3. Проверьте что прошло больше 0.5 сек с последнего клика
