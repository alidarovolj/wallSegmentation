# 🎨 Простая система с двумя цветами

## 🎯 Концепция

Максимально упрощенная система вместо сложных каталогов:
- **Исходный цвет стены** - определяется сканированием AR камеры
- **Цвет перекраски** - выбирается из 8 готовых пресетов
- **Простое переключение** между цветами
- **Быстрое сохранение** результата

## 📋 Компоненты

### 1. SimpleColorManager.cs
**Основной менеджер цветов**
- Управляет двумя цветами: исходный + краска
- 8 готовых пресетов популярных цветов
- Интеграция со сканером цветов
- Flutter API для мобильного приложения

### 2. SimpleColorUI.cs  
**Простой UI для Unity**
- Кнопки: Сканировать, Следующий/Предыдущий цвет, Поменять местами
- Визуальное отображение текущих цветов
- Пресеты цветов с кнопками
- Статус-бар с информацией

### 3. SimpleFlutterBridge.cs
**Упрощенная Flutter интеграция**
- API для сканирования цвета
- Переключение между пресетами
- Получение текущих цветов
- Сохранение проектов

## 🚀 Настройка в Unity

### Шаг 1: Добавление компонентов
На GameObject с AsyncSegmentationManager:
```
1. Add Component → Simple Color Manager
2. Add Component → Simple Flutter Bridge
```

### Шаг 2: Настройка зависимостей
**Simple Color Manager:**
- Color Scanner → ваш ColorScanner
- Segmentation Manager → AsyncSegmentationManager  
- Wall Presenter → ARWallPresenter
- Paint Presets → 8 цветов уже настроены

**Simple Flutter Bridge:**
- Color Manager → Simple Color Manager
- Project Manager → Project Manager (если есть)

### Шаг 3: Создание UI (опционально)
```
1. Create → UI → Canvas
2. Добавить GameObject с Simple Color UI
3. Создать кнопки и связать в Inspector
4. Создать префаб для кнопок пресетов
```

## 📱 Flutter API

### Методы Unity → Flutter:

```csharp
// Сканирование цвета стены
bridge.ScanWallColor("{\"x\": 0.5, \"y\": 0.5}");

// Установка цвета перекраски  
bridge.SetPaintColor("{\"color\": \"#FF5733\"}");

// Переключение пресетов
bridge.NextPaintColor();
bridge.PreviousPaintColor();

// Смена цветов местами
bridge.SwapColors();

// Сброс к исходному
bridge.ResetToOriginal();

// Получение текущих цветов
bridge.GetCurrentColors();

// Сохранение проекта
bridge.SaveProject("{\"name\": \"Моя комната\"}");
```

### События Flutter ← Unity:

```dart
// Изменение цвета
onColorChanged: {
  type: "originalColor" | "paintColor",
  color: "#FF5733", 
  presetIndex: 2
}

// Установка обоих цветов
onColorsSet: {
  originalColor: "#FFFFFF",
  paintColor: "#FF5733",
  presetIndex: 2
}

// Получение текущих цветов
onCurrentColors: {
  originalColor: "#FFFFFF",
  paintColor: "#FF5733", 
  currentPresetIndex: 2,
  presets: ["#FF5733", "#33FF57", ...]
}

// Проект сохранен
onProjectSaved: {
  projectId: "abc123",
  projectName: "Моя комната",
  success: true
}
```

## 🧪 Тестирование

### В Unity Editor:
```
1. Выберите Simple Color Manager в Hierarchy
2. Используйте Context Menu:
   - "Scan Wall Color" 
   - "Next Paint Color"
   - "Swap Colors"
   - "Log Current Colors"
```

### В Play Mode:
```
1. Нажмите "Сканировать цвет" - отсканирует центр экрана
2. Используйте кнопки ← → для переключения пресетов
3. Кнопка "⇄" меняет цвета местами
4. Кнопка "↩" сбрасывает к исходному
```

## 💡 Преимущества простой системы
