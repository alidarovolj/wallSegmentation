# 🔄 Исправление отзеркаливания маски

## 🎯 **Проблема**

Маска горизонтально отзеркалена - левая сторона комнаты показывается на правой стороне экрана.

## 🔍 **Причина из логов**

```
🔄 Режим поворота: 2 (180° (вертикальный flip))
🔄 Горизонтальное отражение: True
```

Система использует **TopFormer** с двойным отзеркаливанием: **180° поворот + горизонтальное отражение**, что создает неправильную ориентацию.

## 🚀 **Быстрое исправление**

### **Шаг 1: Добавить компонент**
1. В Unity создайте пустой GameObject
2. Добавьте компонент `MaskOrientationFix`
3. Назначьте ссылку на `AsyncSegmentationManager`

### **Шаг 2: Применить исправление**
Выберите одну из команд в Context Menu:

#### **🎯 Рекомендуемое исправление:**
```
Context Menu → "Fix Mirroring - No Flip"
```
**Результат**: Отключает отзеркаливание, оставляет маску в правильной ориентации.

#### **🔄 Альтернативное исправление:**
```
Context Menu → "Fix Mirroring - 180° Only"  
```
**Результат**: Только поворот на 180°, без горизонтального отражения.

#### **🧪 Тестирование:**
```
Context Menu → "Test All Orientations"
```
**Результат**: Показывает все 8 комбинаций поочередно (по 3 сек каждая).

## 🔧 **Технические детали**

### **Проблемные настройки (сейчас):**
```csharp
maskRotationMode = 2;    // 180° поворот
flipHorizontal = true;   // + горизонтальное отражение = ОТЗЕРКАЛИВАНИЕ
```

### **Правильные настройки для SegFormer:**
```csharp
maskRotationMode = 3;    // Без поворота
flipHorizontal = false;  // Без отражения
```

### **Альтернативные настройки:**
```csharp
maskRotationMode = 2;    // 180° поворот
flipHorizontal = false;  // Без дополнительного отражения
```

## 📊 **Как проверить исправление**

### **До исправления:**
- Левая сторона комнаты отображается справа
- Правая сторона комнаты отображается слева  
- Маска "зеркальная" относительно камеры

### **После исправления:**
- Левая сторона комнаты отображается слева
- Правая сторона комнаты отображается справа
- Маска точно соответствует тому, что видит камера

## 🎮 **Компонент MaskOrientationFix**

### **Inspector настройки:**
- **Rotation Mode**: 3 (No rotation) 
- **Flip Horizontal**: false (No flip)
- **Apply On Start**: true (Автоматически применять при запуске)

### **Текущие значения (только для чтения):**
- Показывает реальные значения из `AsyncSegmentationManager`
- Обновляется в реальном времени

### **Context Menu команды:**
1. **"Apply Orientation Fix"** - применить текущие настройки
2. **"Fix Mirroring - No Flip"** - быстрое исправление (рекомендуется)
3. **"Fix Mirroring - 180° Only"** - альтернативное исправление
4. **"Reset to SegFormer Defaults"** - сброс к настройкам SegFormer
5. **"Test All Orientations"** - тест всех комбинаций

## 🎯 **Ожидаемый результат**

После применения исправления:
- ✅ Маска будет правильно ориентирована
- ✅ Левая сторона = левая сторона
- ✅ Правая сторона = правая сторона  
- ✅ Отзеркаливание исчезнет

## 🔍 **Проверка в логах**

   Старые настройки: Поворот=2, Отражение=True
