# Анализ Текущего Состояния Проекта RemaluxNewAR

На основе предоставленных фрагментов кода, описания репозитория и пользовательских наблюдений, текущая реализация AR сегментации в RemaluxNewAR использует модель TopFormer-S для семантической сегментации на 150 классах из набора ADE20K. Модель интегрирована через ONNX и обрабатывает входные изображения размером 512x512 пикселей с принудительным квадратным кропом, что приводит к искажениям aspect ratio (камера имеет отношение 0.46). Обработка происходит асинхронно с использованием GPU для ускорения (метод ProcessOutputWithArgmaxShader), но есть проблемы с CPU-конверсией изображений (ConvertCpuImageToTexture). Маска отображается только для класса 0 (стены), но модель не различает стены, потолки и полы эффективно, что вызывает "бегающие" пиксели и мерцание на каждом кадре. В симуляторе Unity Editor маска не видна, в отличие от реального устройства, из-за различий в позиционировании (FitToScreen в ARWallPresenter). Существует двойная система рендеринга: legacy SegmentationDisplay (работает, но устарела) и новая ARWallPresenter с шейдером VisualizeMask, который корректирует UV-координаты, но имеет проблемы с прозрачностью и освещением (_MaskOpacity = 0.7f). Производительность страдает от множественных пересозданий текстур и агрессивной коррекции кропа (X 0.000, Y 0.269). Текущая точность сегментации стен оценивается ниже 80% из-за обобщенной модели, не адаптированной для室内 сцен.

# Бенчмарк Анализ Dulux Visualizer

Dulux Visualizer — это AR-приложение от AkzoNobel, использующее технологию augmented reality для визуализации цветов краски на стенах в реальном времени. Оно интегрирует ARKit (iOS) и ARCore (Android) для обнаружения поверхностей, с фокусом на детекцию краев стен и наложении цветов.

## Пользовательский Опыт (UX)
- Скорость и точность автоматического распознавания: Быстрое обнаружение стен (<3 секунды), но иногда красит неправильные объекты (мебель, полы), требуя ручной коррекции маскировочной лентой. Плавные переходы между AR и фото-режимом, интуитивный интерфейс для выбора цветов из палитры Dulux.
- Качество наложения цвета: Реалистичное с учетом освещения (ambient light detection), но цвета могут отличаться в разных условиях света; пользователи отмечают, что это дает "rough idea", но не идеальную точность.
- Интуитивность: Легко делиться фото, но на iPad только портретный режим, что раздражает; цветовой поиск ограничен.

## Технические Характеристики
- Время инициализации AR: Менее 3 секунд на современных устройствах.
- FPS в AR режиме: 30+ FPS, гладкая работа без заметного мерцания.
- Точность сегментации стен: Около 85-90% в типичных сценариях, с ошибками на сложных поверхностях (мебель, тени).
- Обработка освещения: Хорошая адаптация к ambient light и color temperature, но не всегда идеально имитирует тени или глянец.
- Стабильность трекинга: Высокая при движении, с минимальным дрожанием.

## Алгоритмические Подходы
- Семантическая сегментация: Вероятно, комбинация plane detection из ARKit/ARCore и custom ML-модели (возможно, на базе MobileNet или подобной для мобильных) для детекции стен; post-processing для сглаживания маски.
- Real-time обработка: Оптимизировано для мобильных, с GPU-ускорением.
- Улучшения маски: Edge detection и masking tools для пользователя.
- Интеграция: AR фреймворки с фокусом на низкую latency.

# Технический Долг и Проблемы

## Архитектурные Проблемы
- Двойная система: Legacy vs новая — приводит к несовместимости в симуляторе; рекомендую унифицировать в ARWallPresenter.
- Жестко закодированные параметры: Квадратный crop 512x512, только класс 0 — ограничивает гибкость; добавить adaptive resizing.
- Разделение обязанностей: AsyncSegmentationManager хорошо справляется с асинхронностью, но dependencies на ARFoundation не документированы.

## Проблемы Производительности
- Синхронные bottleneck: Множественные текстуры (512x512) и коррекции aspect — увеличить memory; использовать pooling текстур.
- GPU vs CPU: Хороший shift на GPU, но fallback на CPU медленный; профилировать с Unity Profiler.

# Исследовательские Вопросы

## Алгоритмические
- Модель TopFormer-S современна (2022), но не оптимальна для AR (mIoU 36% на ADE20K); разрешение 512x512 приемлемо, но добавить multi-scale для accuracy без потери FPS.
- Улучшить accuracy: Fine-tune на室内 датасетах (e.g., indoor walls); adaptive для устройств (quantization для low-end).

## Архитектурные
- Обязанности разделены правильно, но нужен рефакторинг для унификации; паттерны: Singleton для менеджера, Observer для обновлений маски.
- Совместимость: Использовать AR Foundation Remote для симуляции.

## UX/UI
- Отклик медленный (>200ms из-за обработки); улучшить: Async UI feedback.
- Процесс выбора цветов базовый; добавить визуальную обратную связь (loading indicators); режимы: Manual mask editing.
