# Руководство по интеграции процедурных поверхностей (Этап 2)

## 🎯 Что создано

Система процедурных 3D-поверхностей, которая:
- Собирает облако точек при касаниях экрана
- Математически аппроксимирует плоскости по облаку точек
- Обнаруживает контуры сегментированных областей на 2D-маске
- Генерирует реалистичные 3D-меши поверхностей

## 📁 Созданные компоненты

### Основные компоненты:
1. **`SurfacePointCollector.cs`** - собирает облако 3D-точек вокруг касаний
2. **`PlaneApproximator.cs`** - математическая аппроксимация плоскости методом PCA
3. **`ContourDetector.cs`** - обнаружение контуров методом марширующих квадратов
4. **`ProceduralMeshGenerator.cs`** - генерация 3D-мешей с триангуляцией
5. **`ProceduralSurfaceManager.cs`** - объединяющий менеджер процесса

### Вспомогательные структуры:
- `PlaneResult` - результат аппроксимации плоскости
- `MeshTriangulation` - результат триангуляции меша
- `ProceduralMeshInfo` - информация о сгенерированном меше
- `Matrix3x3` - математическая матрица 3x3

## 🔧 Быстрая интеграция

### Вариант 1: Полная автоматическая настройка

1. Создайте пустой GameObject в сцене (`Create Empty`)
2. Переименуйте в `ProceduralSurfaceSystem`
3. Добавьте следующие компоненты:
   ```
   - ProceduralSurfaceManager
   - SurfacePointCollector  
   - ContourDetector
   - ProceduralMeshGenerator
   ```
4. В Inspector у `ProceduralSurfaceManager`:
   - ✅ Включите `Enable Auto Process`
   - ✅ Включите `Auto Generate Meshes`
   - Установите `Min Points For Plane: 20`
   - Установите `Min Plane Confidence: 0.6`

5. Запустите сцену - система готова к работе!

### Управление:
- **Касания экрана** → сбор облака точек
- **SPACE** → ручной запуск процесса генерации
- **DELETE** → очистка всех поверхностей
- **C** → переключение сбора точек (если автопроцесс отключен)
- **X** → очистка только облака точек

## 🎮 Рабочий процесс

### Автоматический режим:
1. Касайтесь экрана в области стены/поверхности
2. Система автоматически собирает облако точек
3. При достижении минимума точек (20) запускается процесс:
   - Аппроксимация плоскости по точкам
   - Обнаружение контуров на маске сегментации  
   - Генерация 3D-меша поверхности
4. Результат: реалистичный 3D-меш стены/поверхности

### Ручной режим:
1. Отключите `Enable Auto Process`
2. Соберите точки касаниями
3. Нажмите SPACE для запуска процесса
4. Наблюдайте пошаговое выполнение в консоли

## ⚙️ Настройка параметров

### SurfacePointCollector:
- `Target Class Id: 0` - класс поверхности (0=стены, 1=пол, 2=потолок)
- `Collection Radius: 0.5` - радиус сбора точек вокруг касания
- `Samples Per Tap: 16` - количество образцов на касание
- `Point Size: 0.02` - размер визуализации точек (2см)

### ContourDetector:
- `Target Class Id: 0` - класс для поиска контуров
- `Min Contour Points: 10` - минимум точек в контуре
- `Contour Simplification Tolerance: 2.0` - упрощение контура (пиксели)
- `Min Contour Area: 100` - минимальная площадь контура

### ProceduralMeshGenerator:
- `Generate Colliders: true` - создавать коллайдеры для мешей
- `Generate UVs: true` - создавать UV-координаты
- `Mesh Thickness: 0.01` - толщина меша (1см)
- `Optimize Mesh: true` - оптимизация меша

### ProceduralSurfaceManager:
- `Min Points For Plane: 20` - минимум точек для аппроксимации
- `Min Plane Confidence: 0.6` - минимальная уверенность (0-1)
- `Auto Generate Meshes: true` - автогенерация мешей
- `Enable Auto Process: true` - автоматический процесс

## 🔍 Отладка и диагностика

### Логи системы:
```
[SurfacePointCollector] ✅ Собрано 25 новых точек. Всего: 45
[PlaneApproximator] ✅ Плоскость аппроксимирована: уверенность=0.85
[ContourDetector] ✅ Найдено 3 валидных контуров  
[ProceduralMeshGenerator] ✅ Меш сгенерирован: 120 вершин, 200 треугольников
[ProceduralSurfaceManager] 🎉 Сгенерировано 3 мешей из 3 контуров
```

### Визуальная отладка:
- Облако точек отображается цветными сферами
- Контуры визуализируются линиями на экране
- Сгенерированные меши появляются в сцене как полупрозрачные объекты

### Проблемы и решения:
1. **"Недостаточно точек"** → Больше касаний в одной области
2. **"Низкая уверенность в плоскости"** → Касания должны быть на одной плоской поверхности
3. **"Контуры не найдены"** → Проверьте работу сегментации и настройки фильтров
4. **"Меш не сгенерирован"** → Проверьте валидность контуров и плоскости

## 🚀 Производительность

### Оптимизация:
- Система работает асинхронно - не блокирует основной поток
- Используется кэширование для часто используемых вычислений
- Меши автоматически оптимизируются (удаление дублирующихся вершин)
- GPU readback выполняется в корутинах

### Рекомендации:
- Не более 100 точек в облаке для оптимальной производительности
- Используйте упрощение контуров для сложных форм
- Включайте оптимизацию мешей для финальных результатов

    // Применить покраску к meshObj

```csharp
proceduralSurfaceManager.OnPlaneGenerated += (plane) => {
    // Плоскость аппроксимирована
};

    // Меш сгенерирован - можно применять покраску
};
```

1. Убедитесь что AR сессия активна
2. Направьте камеру на плоскую поверхность (стену)

4. Наблюдайте генерацию 3D-меша поверхности
