# 🔍 Руководство по визуализации контуров и углов

## 🎯 Что это такое?

Система `ContourVisualizer` интегрирует обнаружение углов и контуров прямо в основную маску сегментации. Вместо симулятора теперь черные линии рисуются в углах комнаты поверх реальной AR маски.

## ⚡ Быстрая настройка

### Шаг 1: Добавить ContourVisualizer
1. Создайте пустой GameObject в сцене
2. Назовите его `ContourVisualizer`
3. Добавьте компонент `ContourVisualizer`
4. Компонент автоматически найдет все необходимые компоненты

### Шаг 2: Проверить настройки
В Inspector убедитесь что:
- `Enable Contour Visualization = true`
- `Contour Color = Black` (или любой другой цвет)
- `Show Corners = true` (показывать углы)
- `Show Edges = true` (показывать края)

## 🔧 Как это работает

### Компоненты системы
1. **AsyncSegmentationManager** - создает маску сегментации (как раньше)
2. **EdgeCornerDetector** - анализирует маску и находит углы/края
3. **ContourVisualizer** - комбинирует маску с контурами
4. **ARWallPresenter** - отображает финальный результат

### Процесс визуализации
```
Маска сегментации → Обнаружение углов → Рисование контуров → Комбинирование → Отображение в AR
```

### Углы комнаты
- **Черные крестики** в углах стен

- **Автоматическое обнаружение** характерных точек

### Края стен
- **Черные линии** вдоль контуров
- **Соединение близких точек** для формирования непрерывных линий
- **Адаптивная толщина** линий

## ⚙️ Настройки

### Основные параметры
```csharp
Enable Contour Visualization = true    // Включить систему
Contour Color = Black                  // Цвет линий (черный/красный/любой)
Contour Thickness = 2.0               // Толщина линий в пикселях
Show Corners = true                   // Показывать углы
Show Edges = true                     // Показывать края
```

### Производительность
```csharp
Processing Frame Rate = 5             // Обрабатывать каждые 5 кадров
Use GPU Processing = true             // Использовать GPU (быстрее)
```

## 🎮 Управление

### Контекстные меню (правый клик на компоненте)
- **"Переключить визуализацию"** - включить/выключить контуры
- **"Установить черный цвет"** - черные линии
- **"Установить красный цвет"** - красные линии для отладки
- **"Показать статистику"** - информация о найденных углах и краях

### Программное управление
```csharp
ContourVisualizer visualizer = FindObjectOfType<ContourVisualizer>();

// Включить/выключить
visualizer.SetContourVisualization(true);

// Изменить цвет
visualizer.SetContourColor(Color.red);

// Изменить толщину
visualizer.SetContourThickness(3.0f);

// Получить статистику
visualizer.PrintDetectionStats();
```

## 🔧 Диагностика проблем

### Контуры не отображаются

1. **Проверить компоненты**:
   ```
   ContourVisualizer → Right Click → Show Stats
   ```

2. **Проверить EdgeCornerDetector**:
   - Убедитесь что компонент активен
   - Проверьте настройки обнаружения краев

3. **Проверить AsyncSegmentationManager**:
   - Маска должна работать как обычно
   - `GetSegmentationMask()` должен возвращать текстуру

### Плохое качество обнаружения

1. **Настроить EdgeCornerDetector**:
   ```csharp
   Edge Threshold = 0.3     // Ниже = больше деталей
   Corner Threshold = 0.05  // Ниже = больше углов
   ```

2. **Изменить частоту обработки**:
   ```csharp
   Processing Frame Rate = 3  // Чаще обработка = лучше качество
   ```

### Низкая производительность

1. **Увеличить интервал обработки**:
   ```csharp
   Processing Frame Rate = 10  // Реже обработка = выше FPS
   ```

2. **Отключить GPU обработку** (если проблемы):
   ```csharp
   Use GPU Processing = false
   ```
